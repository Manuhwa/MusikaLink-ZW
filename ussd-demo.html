Booth flow

  1. Dial *288# (or tap Dial) → register if needed
  2. 1 → List produce → pick crop or 6 Other (type name / keypad presets)
  3. Select grade A/B/C → quantity → ward (Madziwa, Bindura, Mazowe, Guruve, Mtoko)
  4. Review prices → 2 List without match (agent alert) or pick a buyer → Accept → escrow
  5. Open Agent / Buyer tabs — listing appears via shared localStorage
Live sync: listings write to browser key musikalink-zw-v2. Keep Agent or Buyer open in another tab to see alerts without a database.
