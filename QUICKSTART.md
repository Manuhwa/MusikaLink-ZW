# Quickstart

```bash
npm install
npm run dev
```

- Landing: http://localhost:3000  
- Farmer USSD: http://localhost:3000/ussd-demo  
- Agent: http://localhost:3000/agent-dashboard  
- Buyer: http://localhost:3000/buyer  
- How it works: http://localhost:3000/how-it-works  

Build check: `npm run build` (must exit 0).

Deploy: import the repo on Vercel — no env vars needed.
